# 숭실 미로 탐색

인공지능입문 팀프로젝트입니다. 에이전트가 3×3 시야로 미로를 탐색해 열쇠를 찾고 출구를 엽니다. 수동으로 조작하거나 같은 맵에서 온라인 DFS, BFS, A* 활용형을 실행해 이동 횟수와 탐색 비용을 비교할 수 있습니다.

[프로젝트 보고서 PDF](output/pdf/soongsil-maze-report.pdf) · [실행별 비교 데이터](results/runs.csv) · [동일 지도에서의 BFS/A* 비교](results/route-tasks.csv)

## 실행

Windows에서 **Python 3.10 이상과 Tkinter**가 필요합니다. Python 표준 라이브러리로 실행할 수 있습니다.

1. 저장소를 내려받아 파일을 모두 풉니다.
2. 폴더 안의 `run_gui.bat`을 더블클릭합니다. PowerShell에서는 `python gui.py`로도 실행할 수 있습니다.
3. 상단의 **맵**과 **알고리즘**을 선택합니다. 수동 모드는 방향키 또는 WASD, 자동 모드는 **실행**, **일시정지**, **한 단계(N)**를 사용합니다.

| 맵 | ID | 단축키 | 고정 함정 |
| --- | --- | ---: | ---: |
| 기본 15×15 | `basic15` | 1 | 1개 |
| 우회 15×15 | `branch15` | 2 | 1개 |
| 도전 21×21 | `hard21` | 3 | 2개 |
| 비교 41×41 | `large41` | 7 | 2개 |

- **고정 함정**은 기본으로 켜져 있습니다. 체크를 풀면 함정 칸이 통로가 됩니다. 설정을 바꾸면 이전 기록을 저장하고 새 실험을 시작합니다.
- 고정 함정을 밟으면 시작점으로 돌아갑니다. 획득한 열쇠, 관측한 지도, 누적 이동 횟수는 유지되며 발견한 함정은 기억합니다.
- 자동 모드의 **기억한 지도**에는 관측한 지형이 표시됩니다. **한 단계**로 행동 이유를 볼 수 있고, 탈출하면 전체 지도와 지나온 경로가 열립니다.
- **순찰 유령**은 도전 21×21의 수동 조작에서 켤 수 있습니다. Space를 누르면 제자리에서 한 턴 기다립니다.
- **R**은 같은 조건에서 새 실험을 시작하고 **Q**는 종료합니다. 프로그램은 종료한 실험의 JSON·TXT를 `logs/`에 저장합니다.

## 알고리즘과 비교 결과

| 방식 | 열쇠를 찾거나 새 영역을 관측할 때 | 위치가 알려진 열쇠·출구까지 |
| --- | --- | --- |
| 온라인 DFS | 미방문 이웃으로 전진하고 막히면 되돌아갑니다. 필요하면 BFS로 탐색이 남은 갈림길에 복귀합니다. | BFS |
| BFS | BFS로 미관측 칸을 새로 볼 수 있는 가까운 위치를 찾습니다. | BFS |
| A* 활용형 | BFS와 같은 방식으로 관측 영역을 넓힙니다. | 맨해튼 거리를 쓰는 A* |

세 방식은 현재 관측과 내부 지도만 이용합니다. 알려진 목표까지의 연결 경로가 아직 기억에 없으면 탐색을 계속합니다.

| 41×41 실행 | 함정 켜짐 이동 | 함정 꺼짐 이동 | 함정 켜짐 누적 확장 | 함정 꺼짐 누적 확장 |
| --- | ---: | ---: | ---: | ---: |
| 온라인 DFS | 1,600 | 1,022 | 504,391 | 44,802 |
| BFS | 854 | 854 | 52,319 | 52,319 |
| A* 활용형 | 854 | 854 | 36,441 | 36,441 |

함정을 끈 조건에서도 DFS가 BFS보다 168칸 더 이동했습니다. BFS와 A* 활용형은 총이동이 같았고, A* 활용형의 누적 확장은 약 30% 적었습니다. 누적 확장은 이웃 상태를 검사한 횟수로, 같은 상태를 다시 검사하면 다시 셉니다.

41×41은 탐색 전략 차이가 잘 보이는 배치를 찾기 위해 후보 10개를 시험해 선택했습니다. 표의 수치는 이 배치에서 같은 조건으로 반복했을 때의 결과입니다.

## 비교 재현

프로젝트 폴더에서 PowerShell을 엽니다. 첫 두 명령은 네 고정 맵을 각각 함정 켜짐·꺼짐으로 실행합니다. 마지막 명령은 기본 15×15에서 열쇠 위치만 바꾸는 비교입니다.

```powershell
.\run_compare.bat --repeat 3 --log-dir logs/traps-on
.\run_compare.bat --repeat 3 --no-traps --log-dir logs/traps-off
.\run_compare.bat --repeat 3 --key-placements --log-dir logs/key-placements
```

실험마다 위치, 열쇠, 내부 지도를 초기화합니다. 실행별 CSV에는 탈출 여부, 이동 및 확장이 기록됩니다. `_routes.csv`는 BFS 실행 중 수집한 같은 내부 지도·출발 상태·목표를 BFS와 A*에 주어 비교한 결과입니다. 이 저장소의 `results/`에는 보고서에 쓴 수치가 들어 있습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `gui.py`, `maze_view.py`, `assets/` | Tkinter 화면과 캐릭터 이미지 |
| `maze_env.py`, `levels.py`, `game.py` | 격자 규칙, 맵 배치, 실험 상태 |
| `agents.py`, `comparison.py` | 자동 탐색과 동일 조건 비교 |
| `main.py`, `experiment_log.py` | 터미널 실행과 실험 기록 |
| `tests/` | 동작 검증 |

테스트는 `python -m unittest discover -s tests`로 실행합니다. GUI 테스트에도 Tkinter가 필요합니다.
